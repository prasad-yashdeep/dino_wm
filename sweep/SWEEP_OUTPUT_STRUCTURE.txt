WHAT'S IN EACH DIRECTORY
═══════════════════════════════════════════════════════════════════════════════════

📋 logs/ - Agent Execution Logs
  ├─ Purpose: Track W&B agent activity and hyperparameter sampling
  ├─ Content: Agent startup, run assignments, command execution, status
  ├─ Size: ~5-10MB per agent
  ├─ View: tail -f sweep_outputs/logs/sweep_agent_1.log
  └─ Keep: Yes (useful for debugging)

🗂️  runs/ - Training Model Outputs
  ├─ Purpose: Store all model checkpoints and training artifacts
  ├─ Content:
  │   ├─ Checkpoints (model weights at various epochs)
  │   ├─ Hydra configuration (exact params used for training)
  │   ├─ Training logs and outputs
  │   └─ Tensorboard logs, etc.
  ├─ Size: ~500MB - 2GB per run × 27 runs = ~10-50GB total
  ├─ Organization: By timestamp (YYYY-MM-DD/HH-MM-SS/)
  ├─ Keep: Yes (models needed for evaluation/inference)
  └─ Cleanup: rm -rf sweep_outputs/runs/ (after archiving best models)

⚙️  configs/ - Sweep Configuration Backups
  ├─ Purpose: Store snapshot of each sweep configuration
  ├─ Content: Copy of sweep.yaml at time of sweep creation
  ├─ Naming: sweep_{SWEEP_ID}_{TIMESTAMP}.yaml
  ├─ Size: ~5KB per config
  ├─ Keep: Yes (useful for reproducing specific sweeps)
  └─ Use: cat sweep_outputs/configs/sweep_abc123*.yaml
